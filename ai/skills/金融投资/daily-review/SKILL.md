# A股超短线每日复盘框架（商用分发版 v1.0）

> **核心理念**：复盘不是写作文，是回答8个关键问题 + 做1个明日计划。
> **参数化**：用户输入自己的持仓和资金量，系统自动适配分析。
> **建议配合**：周期龙头量化交易策略系统（cycle-dragon-trading）做情绪周期定位

---

## 📋 一、用户参数化配置（首次使用填写）

```yaml
# ============ 用户基本信息 ============
总资金量: 100000          # 单位：元
交易风格: "稳健"          # 激进/稳健/保守
单票最大仓位: 25          # 百分比（%）
连续亏损空仓天数: 2       # 连续亏损N天后强制空仓
最大同时持仓: 3           # 最多同时持有几只票

# ============ 持仓数据（每日更新）============
持仓列表:
  - 股票: "铭普光磁(002902)"
    成本价: 25.30
    持仓量: 200
    买入日期: "2026-05-12"
    买入理由: "首板低位启动"
```

## 🔄 二、复盘四步流程

```
Step 1: 数据采集
  → 大盘指数涨跌
  → 成交额/涨跌家数/涨停数/炸板率/晋级率
  → 最高连板/连板梯队
  → 热点板块TOP3
  → 当日关键新闻催化

Step 2: 阶段定位
  → 当前情绪周期阶段（冰点→退潮8阶段）
  → 按阶段匹配应做的买点类型
  → 涨停数趋势修正
  → 晋级率限制检查
  → 结论：今天应该做什么模式

Step 3: 持仓+推荐
  → 持仓个股：按卖出规则逐条检查
  → 筛选明日候选股
  → 每只候选股：买点条件/止损/仓位/三情景

Step 4: 报告输出
  → 按标准化结构输出复盘报告
```

## 📝 三、报告13维标准结构

每日复盘报告必须包含以下13个章节：

| # | 章节 | 内容要点 |
|:-:|:----|:---------|
| 1 | **昨日推荐回填** | 上次推荐股票的实际表现，✅/❌评价 |
| 2 | **新闻催化** | 当日政策/行业/外盘催化，以及风险事件 |
| 3 | **大盘与情绪** | 指数涨跌+成交额+涨停数+封板率+赚钱效应 |
| 4 | **情绪周期定位** | 结合cycle-dragon-trading的阶段判定 |
| 5 | **市场风格定性** | 机构行情 vs 短线接力 vs 容量抱团 |
| 6 | **短线资金进攻方向** | 主线/支线梳理+板块联动检查 |
| 7 | **涨停梯队深度分析** | 高度分布+晋级率+炸板复盘 |
| 8 | **近期活跃股图形趋势** | 大票趋势+高位龙头势态 |
| 9 | **持仓个股深度分析** | 换手率检查+卖出规则检查+资金量适配 |
| 10 | **虚拟账户操作回顾** | 买入/卖出记录+累计盈亏 |
| 11 | **明日推荐（含三情景）** | 每只推荐股：买点条件/止损/仓位/三情景 |
| 12 | **中期展望** | 未来1-4周方向判断 |
| 13 | **纪律检查** | 按禁止规则+卖点条件逐条检查 |

## 🟢🟡🔴 五、明日推荐三情景模板

每只推荐股必须按此格式输出：

```
【股票名称（代码）】— 买点类型/仓位

🟢 超预期：[开盘表现] → [对应操作]
🟡 符合预期：[开盘表现] → [对应操作]
🔴 不及预期：[开盘表现] → [对应操作]
```

**三情景设计原则**：
- **超预期** = 开盘走势比预想强 → 说明判断正确，可以执行
- **符合预期** = 正常范围波动 → 按计划操作
- **不及预期** = 开盘走弱 → 放弃或止损

**不存在**「高开>3%持有」的模板。对于首板模式，高开>3%是放弃信号。

## ⚙️ 七、资金量自适应规则

系统根据用户填写的总资金量自动调整：

```yaml
# 自动计算
单票买入上限: 资金总量 × 单票仓位上限
单日总仓位上限: 资金总量 × 阶段仓位上限
价格过滤线: 资金总量 ÷ 100    # 股价超过此值×100买不起

# 示例：资金量10万，仓位上限25%
单票买入上限: 25000元
价格过滤: 股价 ≤ 1000元/股
```

## 📋 八、推荐股票检查清单

### 推荐前强制检查（逐条打勾）

```
【大盘环境检查】
□ 当前不是退潮期（涨停数<30且炸板>35% → 不推任何股）
□ 当前不是冰点期（涨停数<10 → 不推任何股）
□ 涨停数趋势不是连续3天下降（连续下降→首板成功率大降，仓位砍半或不推）

【市场阶段与策略匹配检查】
□ 当前阶段是主升期/确认期 → 可用A/B1/F模式
□ 当前阶段是分歧期 → 仅用B2/C模式，或空仓不推
□ 当前阶段是萌芽期 → 仅用A/C模式
□ 晋级率<20% → 禁止任何接力，仅做首板或空仓

【个股检查】
□ ① 价格检查：股价×100 ≤ 用户总资金 → 买不起不推
□ ② 封板质量检查：首板炸板≤2次为优，>5次不推
□ ③ 推荐格式完整：买点条件 + 🟢🟡🔴三情景 + 明确不买条件
□ 板块联动：该股所属板块今日涨停≥2只（不是独龙）
□ 换手率：今日换手率<30%（>30%有出货风险，不推）
□ 不是缩量首板（换手率应>3%）
□ 成交额适中（<50亿，过大资金难以持续）

【回避检查】
□ 不是高位缩量加速板（≥5板次日缩量加速 → 不追）
□ 不是退潮期抄底行为
□ 不是跟风股（只做板块龙头）
□ 不在禁区清单内（创业板/维权股等）
```

### 执行流程

```
Step 1: 先判断市场环境 → 环境差 → 不推
Step 2: 再判断阶段匹配 → 阶段不匹配 → 不推
Step 3: 候选股逐个过铁律 → 过不去 → 不推
Step 4: 候选股逐个过技能规则 → 过不去 → 不推
Step 5: 回避检查 → 有回避项 → 不推
Step 6: 全部通过 → 写推荐（三情景+买点条件+不买条件）
Step 7: 无股票通过 → 直接说"今天没有符合系统的票"
```

## 🚫 九、常见错误避免

| 错误 | 纠正 |
|:----|:-----|
| 遗漏新闻催化 | 必须查当日催化，解释为什么涨/跌 |
| 遗漏图形趋势 | 必须看MA5/MA10是否完好 |
| 三情景不完整 | 每只股必须：超预期+符合预期+不及预期 |
| 推荐不考虑阶段 | 用情绪周期判定阶段是否匹配 |
| 持仓分析用主观 | 必须引用量化规则（换手率/卖出条件） |
| 推荐价格超资金 | 必须检查股价×100 ≤ 总资金 |

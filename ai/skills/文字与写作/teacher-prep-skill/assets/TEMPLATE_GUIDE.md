# 教师个性化备课 Skill - 资源模板

本目录用于存放教学资源模板（PPT 模板、Word 教案模板、Excel 班级学情模板等）。

## 当前内置资源

暂无内置资源。可在此目录添加以下类型的资源文件：

- `lesson-template.pptx` — 备课 PPT 模板
- `lesson-plan-template.docx` — 教案 Word 模板
- `class-roster-template.xlsx` — 班级学情表模板
- `homework-template.docx` — 作业模板
- `exam-paper-template.docx` — 试卷模板

## 命名建议

资源文件建议使用英文或拼音命名，避免空格和特殊字符：

```
✅ homework-template-math-grade7.docx
❌ 数学 作业 模板 (1).docx
```

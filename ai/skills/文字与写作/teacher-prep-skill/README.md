# 教师个性化备课助手 (teacher-prep-skill)

> 真正"懂教材、懂学情、懂你"的 AI 备课搭档 — 全学科全学段覆盖

## 核心卖点

- **全学科覆盖**：15 个学科（语数英 + 物化生 + 政史地 + 小学科学 + 音体美 + 信息技术 + 综合实践）
- **全学段贯通**：小学 1-6 + 初中 7-9 + 高中 10-12
- **跨版本适配**：8 大主流版本（人教/苏教/北师大/沪科/外研/华师大/浙教/鲁教）
- **核心能力**：智能备课、学情看板、错题变式、名师模板、应急救场、教学反思

## 数据规模

| 维度 | 数量 |
|------|------|
| 教材版本 | 8 个 |
| 学科 | 15 个（K-12 全学科） |
| 年级 | 12 个（1-12） |
| 教材元数据 | 3272 条 |
| 课标知识点 | 330 个（含完整前置依赖链） |
| 核心章节 | 35 个 + 5 组跨版本映射 |

## 6 大核心能力

| 能力 | 作用 |
|------|------|
| 📝 智能备课 | 6 参数 → 3 版教案 + PPT + 学案 + 作业 |
| 📊 班级学情看板 | 4 维数据 + 30 知识点热力图 + 关注学生 |
| 🎯 错题变式 | 1 原题 → 3 真变式（结构/场景/综合） |
| 📚 名师模板 | 私有 + 共享双轨库 |
| 🚨 应急救场 | 1 分钟出急救版备课 |
| 📈 教学反思 | 自动生成 500-800 字反思周报 |

## 安装

```bash
# 解压后，将 teacher-prep-skill/ 目录复制到你的 AI 平台技能目录
# 在 AI 平台选择"导入本地 Skill"，指向解压目录即可
```

## 系统要求

- Python 3.8+ （仅运行数据生成/测试时需要）
- 任何支持 SKILL.md 规范的 AI Agent 平台

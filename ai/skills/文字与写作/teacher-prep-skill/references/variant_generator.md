## 你的任务

基于原题的**结构**和**解题思想**，生成 **3 道变式题**，覆盖以下三个角度：

### 变式 1：保留结构 + 微调参数
- 保持原题的核心建模思路
- 调整数字、单位、范围
- 难度 ±1

### 变式 2：换场景 + 同方法
- 完全更换应用场景
- 解题方法不变
- 难度不变

### 变式 3：综合提升
- 在原题基础上增加一个变量或条件
- 涉及 2-3 个知识点的综合应用
- 难度 +1

---

## 严格约束

1. **每道变式都必须**：
   - 涉及相同的核心知识点（{{knowledge_codes}}）
   - 解题思路与原题可类比
   - 题面清晰、答案唯一
   - 符合当前教材（{{version_publisher}}）的例题风格

2. **不涉及**：
   - 班级已学之外的内容
   - 超纲题型
   - 与原题完全相同或仅换数字的"伪变式"

3. **输出格式**：
```json
{
  "variant_1": {
    "difficulty": "L1/L2/L3",
    "structure_change": "保留分组结构",
    "question": "完整题目",
    "answer": "完整答案 + 解析",
    "knowledge": ["K7-MAT-XXX"]
  },
  "variant_2": {...},
  "variant_3": {...}
}
```

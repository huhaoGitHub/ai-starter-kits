# 数据说明

本目录的 JSON 数据是 Skill 的核心知识库。

## 三个数据文件

### `curriculum_standards.json`
- **作用**：国家课程标准编码库，所有学科的知识点 + 前置依赖链
- **规模**：330 个知识点
- **编码规则**：
  - `KP-XXX-NNN` = 小学（Kindergarten-Primary）知识点
  - `K7/K8/K9-XXX-NNN` = 初中 7/8/9 年级知识点
  - `KH-XXX-NNN` = 高中（Kindergarten-High）知识点
- **学科代码**：
  - `MAT` 数学 / `CHI` 语文 / `ENG` 英语
  - `PHY` 物理 / `CHEM` 化学 / `BIO` 生物
  - `POL` 道德与法治 / `HIST` 历史 / `GEO` 地理
  - `SCI` 小学科学 / `IT` 信息技术
  - `PE` 体育与健康 / `ART` 美术 / `MUS` 音乐
  - `COMP` 综合实践
- **难度等级**：`L1` 基础 → `L5` 综合

### `textbook_versions.json`
- **作用**：8 大教材版本 × 15 个学科 × 12 个年级 的元数据
- **规模**：3272 条记录
- **8 大版本**：
  - `pep` 人教版（80%+ 全国覆盖）
  - `su` 苏教版（江苏）
  - `bsd` 北师大版（华北/西北）
  - `shk` 沪科版（上海）
  - `fltrp` 外研版（英语）
  - `ecnu` 华师大版（华东）
  - `zjedu` 浙教版（浙江）
  - `sdedu` 鲁教版（山东）
- **数据状态**：
  - `data_ready` - 数据完整可查
  - `data_partial` - 部分就绪
  - `planned` - 计划补充

### `knowledge_graph.json`
- **作用**：教材章节结构 + 跨版本等价映射
- **规模**：35 个核心章节 + 5 组跨版本映射
- **跨版本映射**：通过课标编码把不同版本的"同名章节"等价连接

## 15 个学科的覆盖范围

### 小学 (1-6)
- 语文、数学、英语(3-6)、科学、体育与健康、美术、音乐、综合实践

### 初中 (7-9)
- 语文、数学、英语
- 物理(8-9)、化学(9)、生物
- 道德与法治、历史、地理
- 信息技术、体育与健康、美术、音乐、综合实践

### 高中 (10-12)
- 语文、数学、英语
- 物理、化学、生物
- 道德与法治、历史、地理
- 信息技术（含 AI）、体育与健康、美术、音乐、综合实践

## 数据生成

如需重新生成数据，运行：
```bash
python scripts/generate_data.py
```

会覆盖本目录的三个 JSON 文件。
